# 내려다보던 도시에서 내려오기

올가 토카르추크 단편 「체게바라」를 1981년 겨울 바르샤바 안에서 걸어서 경험하는 브라우저 3D 작품이다. Three.js와 Vite로 만들었다.

공개 주소: https://ysys143.github.io/che-guevara-warsaw-1981/

## 조작

첫 화면은 바르샤바 지도다. 장소를 누르면 원문 인용과 그 장소의 장면이 열린다. 원작 순서대로 걷는 서사 플레이는 '이야기로 플레이'에서 시작한다.

지도: 끌기 또는 W A S D 이동, 오른쪽 끌기 또는 Z C 회전, 휠 또는 + − 확대.

장면 안:

- W A S D 또는 바닥 클릭: 걷기
- 끌기 또는 Z C: 돌기
- E 또는 클릭: 하기
- ← →: 이전·다음 대사
- Shift+← →: 이전·다음 챕터
- G: 근거 표시, Q: 원문 근거

## 실행

```
npm install
npm run dev
```

자료가 부족해 상상으로 채운 부분은 화면 오른쪽 아래에 표시한다. 전체 목록은 앱의 열람실에 있다.

## 저작권

- 코드는 저작자의 허락 없이 재사용할 수 없다.
- 작품 인용은 짧은 근거 표시를 위한 것이며, 해당 저작물의 권리는 저작권자에게 있다. 원문 전문은 이 저장소에 없다.
- 지도 데이터는 © OpenStreetMap 기여자이며 ODbL을 따른다. `public/data/city.json`은 이 데이터에서 파생했으므로 같은 조건이 적용된다.
